# TDM Insight 📱

**TDM Insight** is an Android mobile application designed to assist medical and pharmaceutical professionals with Therapeutic Drug Monitoring (TDM) calculations, dosing adjustments, and pharmacokinetic evaluation.

---

## 🚀 Features

* **Patient Data Entry:** Intuitive forms for patient demographic and clinical input.
* **Pharmacokinetic Calculations:** Supports Pre-dose, Post-dose, and Pre/Post calculation workflows for drug level monitoring.
* **Calculation Explanation:** Detailed step-by-step breakdown of equations and recommendations.
* **Shared Workflow State:** Seamless multi-step wizard navigation powered by Jetpack Compose and shared ViewModels.

---

## 🛠️ Tech Stack & Requirements

* **Language:** Kotlin
* **UI Framework:** Jetpack Compose (Material 3)
* **Architecture:** MVVM (Model-View-ViewModel) with Navigation Compose
* **Build System:** Gradle (Kotlin DSL / Version Catalogs)
* **Minimum SDK:** Android 8.0 (API level 26)
* **Recommended JDK:** JDK 21
